# Introduction

In this section, you will become familiar with the essential tools used in ethical hacking.
These tools form the backbone of practical pentesting activities, enabling you to perform scanning, enumeration, vulnerability detection, exploitation, and traffic interception.
You will not only learn how to use each tool, but also understand when and why to use them, their strengths, limitations, and how to chain them effectively in an attack workflow.

This section is structured around core functional categories:

- **Port Scanners:** Tools like Nmap and Masscan help you map out a target's attack surface by identifying open ports and services.
You'll learn about advanced scanning techniques, Nmap scripting, and stealth scanning.
- **Vulnerability Scanners:** Nikto, OpenVAS, and Nessus assist in identifying known vulnerabilities.
You'll compare their outputs and learn how to interpret results accurately.
- **Interception Proxies:** Burp Suite is essential for inspecting and modifying HTTP/S traffic between clients and servers.
You'll explore active and passive scanning, repeater, intruder, and extensions.
- **Exploitation Frameworks:** Metasploit and SQLmap automate the exploitation process.
You'll learn how to set up handlers, craft payloads, and run auxiliary modules.
- **Wireless Tools:** Aircrack-ng and related utilities will be introduced for monitoring and attacking wireless networks.
